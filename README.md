# ОКБ «Спецтяжпроект» — сайт

Одностраничное приложение (SPA) на чистом HTML/CSS/JS без сборки и зависимостей.
Публикуется через GitHub Pages из ветки `main`, корень репозитория.

## Структура

```
index.html      единственная страница: разметка, стили и данные
img/            фотографии проектов и техники (.jpg + .webp)
404.html        страница ошибки
robots.txt      правила для поисковых роботов
sitemap.xml     карта сайта
.nojekyll       отключает обработку Jekyll на GitHub Pages
```

## Как править содержимое

Весь контент вынесен в массивы JavaScript в конце `index.html`:

| Массив       | Что содержит                          |
|--------------|---------------------------------------|
| `services`   | услуги                                |
| `why`        | блок «Почему заказчики возвращаются»  |
| `nums`       | цифры компании                        |
| `steps`      | этапы работы                          |
| `projects`   | проекты (отрасли для фильтра — поле `tag`) |
| `equipment`  | техника                               |
| `knowhow`    | инженерные решения                    |
| `timeline`   | история компании                      |
| `comps`      | компетенции                           |
| `certs`      | допуски и сертификаты                 |
| `quotes`     | отзывы                                |
| `partners`   | заказчики и партнёры                  |
| `articles`   | карточки раздела «Экспертиза»         |
| `faq`        | вопросы и ответы                      |

Отрасли на главной и чипы фильтра считаются автоматически из `projects`, вручную их править не нужно.

## Как добавить фотографию

1. Положить файл в `img/` (желательно и `.jpg`, и `.webp`).
2. Добавить запись в объект `IM` в начале скрипта: ширина, высота и режим вписывания.
   `fit: "cover"` — фото заполняет карточку; `fit: "contain"` — вписывается целиком
   на размытом фоне (для очень широких или вертикальных снимков).
3. Указать ключ в поле `img` нужного проекта.

## Что нужно доделать перед боевым запуском

- Форма заявки пока ничего не отправляет. Нужен обработчик: Formspree, собственный
  PHP-скрипт или e-mail-шлюз.
- Карта в разделе «Контакты» — схематичная. Заменить на виджет Яндекс Карт.
- Раздел «Экспертиза» содержит карточки-заглушки. Тексты статей нужно
  разместить отдельными страницами и заменить ссылки.
- Заменить `Демонстрационная версия сайта` в подвале и добавить реквизиты и
  политику обработки персональных данных.
